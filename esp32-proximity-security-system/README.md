# 🚨 ESP32 Proximity Security System

A real-time embedded system built using ESP32 that detects proximity and triggers alerts using sensors, wireless communication, and visual feedback.

---

## ⚙️ Key Features

- Ultrasonic distance sensing with filtering
- LED bar graph visualization
- LCD display for live feedback
- BLE communication (ARM, DISARM, STATUS)
- WiFi web dashboard
- Buzzer alert system
- Real-time system logic

---

## 🔄 System Flow

1. Sensor reads distance  
2. ESP32 processes and filters data  
3. LEDs update based on proximity  
4. System checks trigger conditions  
5. Alerts activate if needed  
6. Status sent via BLE, LCD, and web
